# AutoHub Car Marketplace

Production-oriented frontend foundation for a reusable car marketplace built with Next.js 15, React, TypeScript, Tailwind CSS, shadcn/ui primitives, React Icons, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run lint
npm run build
```

The current data layer uses typed local modules and service contracts so a future WordPress REST adapter can replace dummy data without coupling API response shapes to UI components.
